Conectar con GitHub

Solo se guarda en este celular o computador. Nunca se publica.

¿Cómo saco la clave?
  1. GitHub → tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: "Only select repositories" y escoge SOLO el de tu tienda.
  3. Permissions → Repository permissions → Contents: "Read and write".
  4. Ponle vencimiento (90 días) y copia la clave aquí. No la compartas con nadie.

Copia de seguridad

Crear link de acceso

Para la dueña del negocio. Ella no verá nada de GitHub: abre el link, escribe la clave de acceso que tú le pongas aquí y ya puede cambiar y publicar. Lo que ella publique lo ves tú y lo que publiques tú lo ve ella (al abrir el panel carga lo último publicado).

Mándale el link por un lado y la clave por otro (el link por WhatsApp y la clave en persona o por llamada). Si algún día cambias la clave (token) de GitHub, crea un link nuevo.
